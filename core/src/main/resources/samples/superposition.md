# サンプル: 重ね合わせ

1 量子ビットに H ゲートを適用して |0⟩ と |1⟩ の重ね合わせを作り、測定します。

## 実行手順

1. `superposition.circuit.json` を **量子OS → 回路を検証** で検証します。
2. 実行構成から実行します。seed を空欄にするとサービスがシードを選び、結果にそのシードが表示されます。
3. 結果ペインの **再実行** で、同じ seed と shots による再実行ができます。

## 期待される結果

観測されるキーは `0` と `1` の範囲内で、回数の合計は shots と一致します。
それぞれが shots の半分ちょうどになることは要件ではありません。
再現性は同一イメージ・サービスビルド・実行環境・回路・seed に限ります。
