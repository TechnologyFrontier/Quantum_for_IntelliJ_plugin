# サンプル: ベル回路

量子ビット 0 に H、0→1 に CX を適用してベル状態を作り、両方を測定します。

```json
{"schema_version":1,"n_qubits":2,"operations":[
  {"op":"h","qubits":[0]},
  {"op":"cx","qubits":[0,1]},
  {"op":"measure","qubits":[0,1]}]}
```

## 実行手順

1. `bell.circuit.json` を **量子OS → 回路を検証** で検証します。
2. 実行構成で shots を 1,024 にして実行します。
3. **Quantum Results** でビット列・回数・比率を確認します。ビット順は measured_qubits の順です。

## 期待される結果

1,024 ショットで観測されたキーが `00`・`11` の範囲内であり、回数の合計が 1,024 であること。
両者が 512 回ずつになることは要件ではありません。
